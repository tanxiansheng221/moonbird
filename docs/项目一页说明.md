# 怒鸭大战（MoonBird）— 项目一页说明

**一句话**：100% MoonBit 编写的 WASM-4 弹弓物理游戏，自研 2D 刚体引擎，12 关 + 4 种技能鸟 + TNT 连环爆炸。

## 亮点

1. **自研物理引擎（非现成库）**：`birdcore` 独立模块实现 Vec2 / 刚体 / AABB+圆碰撞 / 休眠系统 / 材质伤害 / 范围爆炸与链式殉爆，可作为 MoonBit 2D 物理可复用产出。
2. **固定步长游戏循环**：accumulator 模式（`core.Clock`），掉帧最多追补 MAX_STEPS 步防死亡螺旋——可复用为 MoonBit 游戏循环模板。
3. **完整游戏闭环**：Title / 关卡选择 / Playing / Pause / 结算状态机；WASM-4 disk 12 字节存档（解锁+星级+最高分，v1 兼容）；音调合成音效（材质差异化频率）。
4. **质量保障**：白盒+黑盒测试覆盖弹道/碰撞/堆叠稳定性/爆炸/存档/状态机，`moon test` 11/11 全绿。

## 技术栈

MoonBit · WASM-4 幻想机（160×160，4 色调色板，wasm-gc 目标）

## 操作

鼠标拖拽弹弓发射（轨迹预览）· X 键技能（黄冲刺 / 蓝三分裂 / 黑爆炸）· Enter 暂停
