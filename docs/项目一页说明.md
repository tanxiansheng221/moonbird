# 怒鸭大战（MoonBird）— 项目一页说明

> 更新：2026-10-03

**一句话**：100% MoonBit 逻辑的弹弓物理游戏，自研 2D 物理引擎 `birdcore`，12 关 + 4 种技能鸭 + TNT 连环爆炸，在线可玩。

**在线试玩**：https://tanxiansheng221.github.io/moonbird/

## 亮点

1. **自研物理引擎（非现成库）**：`birdcore` 独立模块实现 Vec2 / 质点动力学 / 圆+AABB 碰撞 / 冲量响应 / 休眠系统 / 材质伤害（木石冰猪阈值-血量表）/ 范围爆炸与连锁殉爆——MoonBit 2D 物理可复用产出。
2. **固定步长游戏循环**：accumulator 模式（`core.Clock`），掉帧最多追补 MAX_STEPS 步防死亡螺旋——可复用为 MoonBit 游戏循环模板。
3. **双运行线共享内核**：webgame 线（js target + Phaser 渲染，1280×720，已上线）与 WASM-4 复古线（160×160）共用同一 `birdcore`，物理行为一致性由单测保障。
4. **质量保障**：`moon test` 11/11 全绿 + Node 无头探针 20+（逐关静置/实弹命中/弹道追踪）+ GitHub Actions CI（构建+测试+smoke→自动部署 Pages）。
5. **工程排错实证**：部署链路五连障（坏 script 标签/CDN 文件名/ESM 导出/CI 误报/备份回退）逐一定位修复，最终线上双绿。

## 技术栈

逻辑：MoonBit（birdcore 物理 + webgame 游戏层 + exports API 25 个）
渲染：Phaser 3.87 ESM（CDN，仅表现层与输入转发，零游戏逻辑）
部署：GitHub Actions → GitHub Pages

## 操作

鼠标拖拽弹弓发射（轨迹预览与实弹同参数）· X 键技能（黄：速度×1.6 / 蓝：±22°分裂 / 黑：爆炸）· 猪清零自动进下一关，12 关通关
