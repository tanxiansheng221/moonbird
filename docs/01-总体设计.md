# 《怒鸭大战》总体设计文档

> 项目代号：moonbird（月鸟）
> 技术红线：全程仅使用 MoonBit 语言开发（赛事硬性要求）
> 最后更新：2026-10-03（按代码实况校准，所有参数均可 在源码中对应）

## 1. 项目定位

一款弹弓物理射击网页游戏（玩法致敬愤怒的小鸟，角色/美术/命名全部原创），
同时沉淀可复用产物：

1. **可复用的 2D 物理模块**（`birdcore`：重力积分、圆/AABB 碰撞、冲量响应、休眠系统、材质破坏、范围爆炸）
2. **固定步长游戏循环模板**（accumulator + MAX_STEPS 防死亡螺旋，`core.Clock`）
3. **双端运行验证体系**（moon test 单测 11/11 + Node 无头探针 20+ 个 + GitHub Actions CI/CD）

## 2. 实际架构（双运行线，同一物理内核）

> 设计早期只有 WASM-4 单线；开发中演化出双线，两线共享 `birdcore` 物理内核。

| 线 | 目录 | 渲染 | 状态 |
|---|---|---|---|
| **webgame 线（主线，已上线）** | `webgame/` + `phaser/` | MoonBit 编译 js target + Phaser 3.87 渲染（CDN ESM） | GitHub Pages 在线可玩，1280×720 |
| maze 线（WASM-4 复古线） | `maze/birdgame.mbt` + `statemachine.mbt` | WASM-4 幻想机 160×160 | 可构建，独立玩法实现 |

- webgame 线的逻辑全部在 MoonBit（`game.mbt` 状态机/伤害/爆炸/粒子，`levels.mbt` 12 关布局，
  `exports.mbt` 对前端的 25 个 `api_*` 接口），**JS 层只做渲染与输入转发**（红线内：逻辑零 JS）。
- 部署：GitHub Actions 自动 `moon build --target js --release` → 组装站点 → Pages 发布。

## 3. 实际模块划分（与代码一一对应）

```
wasm4demo/
├── birdcore/
│   ├── core/core.mbt        物理内核：Vec2 / Entity / collide / resolve / explode / 休眠 / 材质表
│   └── phys_test/           物理单测
├── webgame/                 主线游戏逻辑（js target）
│   ├── types.mbt            常量与鸟类型分配（ANCHOR/DRAG_R/LAUNCH_K/NUM_LEVELS…）
│   ├── levels.mbt           12 关布局（load_level1~12）
│   ├── game.mbt             状态机 / 伤害结算 / 爆炸 / 粒子 / 镜头 / 事件
│   ├── exports.mbt          前端 API（25 个 api_*）
│   └── *_wbtest.mbt         白盒测试
├── phaser/src/              渲染层（JS 仅表现）
│   ├── main.js              Phaser.Game 装配
│   ├── game.js              GameScene：输入→api_pointer、事件→特效/音效、实体→精灵
│   └── art.js               程序化贴图生成（零外部素材）
├── maze/                    WASM-4 复古线（独立实现，含 armed 防开局自爆）
└── wasm4/                   WASM-4 FFI 封装（maze 线依赖）
```

**分层铁律**：`birdcore` 不依赖任何渲染/平台 API —— 物理可独立 `moon test`，
"可复用物理模块"这一卖点成立的前提（已兑现：webgame 与 maze 两线共用同一内核）。

## 4. 游戏状态机（webgame 实况）

```
Aiming(0) → Flying(1) → Settling(2) → 回 Aiming（自动下一发）
                          ↓ 猪清零
                    check_level_clear → +1000 → 自动 load_level(下一关)
                          ↓ 第 12 关清空
                    won = true（通关）
```

- 静止判定：实体休眠 + SETTLE_TIMEOUT=2.5s 兜底
- 鸟死亡三路径：高速接触自爆（sp>110）/ 出界 / 停止——**统一调用 apply_blast**（skip_req 放弃除外）
- 失败判定：无独立 Fail 态，鸟用尽可 skip 直接推进

## 5. 功能范围（实况）

### 5.1 鸭（4 种，`types.mbt::bird_type_for_level`）
| 鸭 | 技能（实测实现） | 分配关卡 |
|---|---|---|
| 红 | 无技能基准弹道 | L1~3、7、11 |
| 黄 | 飞行中速度 ×1.6（clamp 520），限一次 | L4、L9 |
| 黑 | 触发即爆（复用 TNT 爆炸） | L5、L10、L12 |
| 蓝 | ±22° 分裂出 2 只（速度 ×0.95） | L6、L8 |

### 5.2 结构方块（3 材质 + TNT，参数见 02 文档材质表）
木 / 石 / 冰 + TNT（受击阈值 8 即爆，爆炸半径 165、伤害 180、冲量 260，支持连锁殉爆——统一结算防死循环）。

### 5.3 关卡（12 关实况构成，`levels.mbt`）
| 关 | 猪 | TNT | 木 | 石 | 冰 | 鸭 |
|---|---|---|---|---|---|---|
| L1 | 1 | 1 | 3 | 1 | 1 | 红 |
| L2 | 2 | 1 | 2 | 0 | 4 | 红 |
| L3 | 2 | 1 | 3 | 4 | 2 | 红 |
| L4 | 1 | 1 | 3 | 0 | 1 | 黄 |
| L5 | 2 | 1 | 1 | 5 | 0 | 黑 |
| L6 | 3 | 0 | 0 | 0 | 3 | 蓝 |
| L7 | 2 | 0 | 4 | 2 | 0 | 红 |
| L8 | 2 | 1 | 4 | 0 | 2 | 蓝 |
| L9 | 2 | 1 | 1 | 3 | 1 | 黄 |

| L12 | 3 | 2 | 0 | 6 | 0 | 黑 |

- 共 25 猪 / 12 TNT；`LEVEL_X_OFF=120`：全部结构整体右移，远离弹弓留足弹道空间
- 世界宽 1200，地面 Y=465，镜头 0..(WORLD_W-1280 与 0 取大)

### 5.4 得分（实况）
- 猪击杀 +500、方块破坏 +150、通关 +1000（无星级/存档，见 §7 未做项）

## 6. 美术方向（全程序化，零外部素材）

- webgame 线：`art.js` 运行时生成纹理（Canvas 程序化绘制 → Phaser 贴图），1280×720
- maze 线：WASM-4 framebuffer 程序化像素绘制，160×160
- 鸭/狐狸（反派）/方块/背景全部程序化，无版权风险
