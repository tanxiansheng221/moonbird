# 物理引擎设计（birdcore 模块）— 实况版

> 定位：可独立单测的纯逻辑模块，不依赖任何平台 API（webgame / maze 两线共用）。
> 本文所有数值 = 源码当前真值（2026-10-03 校准），出处见括号。
> 设计取舍：弹弓射击类不需要完整刚体求解器，用「质点动力学 + 简化形状」——实测手感成立。

## 1. 实体模型（core.mbt::Entity）

```
struct Entity {
  mut px, py, vx, vy : Double   // 位置/速度（世界坐标，Y 向下，单位=像素）
  kind  : EntityKind            // BirdK | PigK | BlockK | TntK | GroundK
  shape : Shape                 // Circle(r) | Box(w,h) | Static（静态不积分）
  mat   : Material              // 材质（密度/弹性/阈值/血量查表）
  mut hp : Double               // 血量，<=0 破坏
  mut asleep : Bool             // 休眠标记
  mut sleep_t : Double          // 低速计时
}
```

- 鸟/猪/TNT：圆形（猪 r=18；鸟 60×60 外接）；方块：AABB **不旋转**（碎裂即消失+碎片粒子视觉补偿）
- 地面：Static（密度 1e5，不可破坏）

## 2. 积分（core.mbt 实况）

- 固定步长 `DT = 1/60`；webgame 侧 accumulator（`core.Clock` + FRAME_DT=1/60，MAX_STEPS 防死亡螺旋）
- 半隐式欧拉（先速度后位置）
- `GRAVITY = 300` px/s²
- 速度上限 `V_MAX = 700`（单步位移 < 最小碰撞半径，防穿透）

## 3. 碰撞检测与响应

### 3.1 检测
- 圆-圆 / 圆-AABB（clamp 最近点法）/ AABB-AABB（区间重叠），见 `collide()` 返回 `Contact{nx,ny,depth}`
- **不做空间哈希**：每关实体 <40，O(n²) ≈ 800 对/步，js target 实测够快

### 3.2 响应（`resolve()` 冲量法）
```
j = -(1+e) * v_rel_n / (1/m1 + 1/m2)
分离修正：按质量反比推开，slop = 0.5px 容差
```
弹性系数实况：木 0.2 / 冰 0.1 / 石 0.1 / 猪 0.3 / 鸟 0.3 / TNT 0.2 / 地面 0.2

### 3.3 堆叠稳定性（已实测成立）
1. **休眠**：低速计时 → asleep=true 跳过积分；高速碰撞唤醒
2. **slop 容差** + 质量反比分离
3. 单测覆盖：堆叠稳定性回归（`moon test` 11/11 中含）

## 5. 爆炸（实况）

- 入口：`World::explode(ex, ey, radius, power, damage)` 返回 `BlastEvent[]`（**只返回受击事件，扣血由 game 层统一结算**）
- 参数：半径 = `TNT_RADIUS × 3 = 165`px，冲量 power = 260，伤害 damage = 180（随距离 falloff）
- 同帧多爆统一结算（先收集后触发新 TNT，防死循环）；爆炸伴随震屏 shake + ev_blast 事件

## 6. 伤害结算与防自爆（2026-10-03 关键修复记录）

- 伤害管线：`world.step(DT)` 返回 damages → game 层 `h.target.hp -= amount` → 死亡处理（猪+500 / 方块+150 / TNT→apply_blast 连锁）
- **开局自爆问题**（实战踩坑）：初始布局实体重叠 → solver 首帧大分离冲量 → 误触伤害
  - maze 线修法：`armed` 门控——加载后物理照跑、伤害冻结，首次发射才解锁
  - webgame 线修法：布局重叠清理 + 鸟死亡三路径（高速接触/出界/停止）统一 `apply_blast`，
    逻辑层静置探针 900 帧实测无自爆（score 0、无事件）
- 事件系统：`take_events()` 返回 6 元组 `(ev_shot, ev_blast, ev_clear, ev_boom, ev_impact, ev_score)`，前端接音效/特效

## 7. 弹弓（types.mbt / game.mbt 真值）

- 锚点 `ANCHOR_X=180, ANCHOR_Y=390`；拖拽半径 `DRAG_R=96`
- 发射初速：v = `LAUNCH_K(26)` × (anchor − drag)，上限 `LAUNCH_VMAX=900`
- 轨迹预览：`api_traj_point` 逐点采样（同一 K 值，预览与实弹一致）
- 注：K=26/VMAX=900 偏强，实机试射校准列入待办（平射射程富余较大）
