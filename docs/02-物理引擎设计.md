# 物理引擎详细设计（core 模块）

> 定位：可独立单测的纯逻辑模块，不依赖任何平台 API。
> 设计取舍：弹弓射击类游戏不需要完整刚体求解器，用「质点动力学 + 简化形状」即可，
> 这是同类游戏通行做法，手感足够且实现量小一个量级。

## 1. 实体模型

```
struct Entity {
  mut px : Double        // 位置（世界坐标，单位=像素，原点=弹弓锚点）
  mut py : Double
  mut vx : Double        // 速度
  mut vy : Double
  kind  : EntityKind     // Bird | Pig | Block | Tnt | Ground
  shape : Shape          // Circle(r) | Box(w, h) | Static(静态不积分)
  mat   : Material       // 材质引用（密度/硬度/血量）
  mut hp : Double        // 血量，<=0 破坏
  mut asleep : Bool      // 休眠标记
  mut sleep_t : Double   // 低速计时
}
```

- 鸟、猪、TNT：圆形（半径 5~7px）
- 方块：轴对齐矩形（AABB），**不做旋转**——破坏类游戏里旋转收益低、
  稳定性成本高，方块被击碎后直接消失并生成碎片粒子（视觉补偿）
- 地面/不可破坏基座：Static，不参与积分，只参与碰撞

## 2. 积分：半隐式欧拉 + 固定步长

```
dt = 1/60（固定步长）
每帧：render 回调可能被调用 0~N 次，accumulator 累积真实时间，
循环补齐固定步长 update(dt)，剩余不足一步的时间滚入下一帧。
```

- 半隐式欧拉（先更新速度再更新位置）对抛物线弹道稳定性远好于显式欧拉
- 重力 g = 300 px/s²（WASM-4 世界尺度下调参，弹射射程约 400px）
- 速度上限 clamp（防止穿透：v_max = min_size/dt 保证单步位移 < 最小碰撞体半径）

## 3. 碰撞检测与响应

### 3.1 检测（宽相→窄相）
- 宽相：统一用外接圆做圆-圆粗判（便宜）
- 窄相三种：
  - 圆-圆：距离 < r1+r2
  - 圆-AABB：clamp 求最近点法
  - AABB-AABB：区间重叠
- **不做空间哈希**：实体数上限约 40/关，O(n²) ≈ 800 对/步，WASM 下完全够快

### 3.2 响应（冲量法，恢复系数）
```
法线方向相对速度 v_rel_n < 0 时才响应
冲量 j = -(1+e) * v_rel_n / (1/m1 + 1/m2)
e（弹性系数）: 鸟=0.3, 木=0.2, 冰=0.1, 石=0.1, 猪=0.3
分离修正：按质量反比沿法线推开重叠深度（80% 每步，防抖动用 slop=0.5px 容差）
```

### 3.3 静态堆叠稳定性三板斧（重点，M1 必须验证）
1. **休眠**：速度模 < 4 px/s 持续 1s → asleep=true，跳过积分；
   被高速实体（>50 px/s）碰撞则唤醒
2. **slop 容差** + 每步 80% 分离，消除堆叠微抖
3. **迭代次数 2**：每固定步内碰撞解算跑 2 遍迭代（塔式堆叠必需）

验收标准：10 个方块叠两层塔，静置 5 秒无可见位移（单测断言位置漂移 < 1px）。

## 4. 破坏系统

### 4.1 伤害公式
```
冲击强度 = 法线相对速度 * 较小质量归一化
damage = impact > mat.threshold ? impact - mat.threshold : 0
hp -= damage
```

| 材质 | 密度 | 阈值 | 血量 |
|---|---|---|---|
| 木 | 1.0 | 60 | 100 |
| 冰 | 0.6 | 40 | 50 |
| 石 | 2.5 | 120 | 250 |
| 猪 | 0.8 | 50 | 120（受直接鸟击额外 ×2） |
| TNT | 0.9 | 30 | 触发即爆 |

### 4.2 爆炸
- 爆炸半径 R=40px，对圆心在 R 内的实体施加：伤害 = 200*(1-d/R)，径向冲量
- 同帧多爆炸源去重：先收集所有爆炸事件，统一结算后再触发新 TNT（队列，防死循环）
- 碎片：方块/猪破坏时生成 4~6 个粒子（纯视觉，无碰撞，重力+寿命）

### 4.3 得分事件
破坏结算时产生 ScoreEvent（来源实体、分值、位置），由游戏层消费显示飘字。

## 5. 弹弓

- 拖拽：按下时记录锚点，拖动把鸟位置限制在锚点周围半径 24px 的圆内
- 发射初速：v = k * (anchor - drag_pos)，k≈14，上限 v_max=380
- 轨迹预览：从发射点以 dt=1/30 采样 12 个点画虚线（含重力，不含空气阻力——不设空气阻力，保持弹道纯抛物线）
- 发射后弹弓皮筋回弹动画（2 根线段插值回锚点，纯渲染层）

## 6. 鸟技能实现

| 鸟 | 实现 |
|---|---|
| 黄·加速 | vx,vy 同比例 ×2（clamp 上限），只允许一次，技能后残影粒子 |
| 蓝·分裂 | 原鸟销毁，生成 3 只 r 减半、速度分别偏转 -15°/0°/+15° 的小鸟，回合以最后一只静止结算 |
| 黑·爆炸 | 触发时进入爆炸事件队列，复用 4.2 爆炸逻辑 |

## 7. 单元测试计划（moon test，随代码提交）

1. Vec2 运算纯函数：加法/点积/模长边界（零向量）
2. 弹道一致性：给定初速，t 时刻位置 == 解析解（解析解即抛物线公式，误差 < 0.01）
3. 圆-AABB 碰撞：圆在盒内/边角/外三种位置
4. 冲量守恒：等质量对撞 e=1 时交换速度
5. 堆叠稳定性：塔静置 5s 漂移 < 1px（回归测试，物理参数改动必跑）
6. 破坏阈值：低于阈值不扣血；TNT 连锁去重（两 TNT 相邻只爆一轮）
7. 静止判定：全场 asleep → 回合结束
